# DockerMind — AI DevOps Agent (Phase 1)

Self-hosted AI agent that monitors Docker containers, analyzes logs with a local LLM,
and auto-heals containers. Master-slave architecture with mTLS security.

## Requirements

- Ubuntu server with Docker + Docker Compose installed
- 4GB RAM minimum (phi3:mini model uses ~2.2GB)
- No GPU needed — CPU inference only
- Ports 8000 (master API) and 8080 (slave agent) open

## First-time setup

```bash
# 1. Clone / copy the project
cd dockermind

# 2. Generate mTLS certificates
bash scripts/gen_certs.sh

# 3. Create your .env file
cp .env.example .env
nano .env          # set a strong API_SECRET

# 4. Build and start everything
docker compose up --build
```

The first run will download the phi3:mini model (~2.2GB). This takes a few minutes.
Subsequent starts are instant.

## Verify it's working

```bash
# Health check
curl http://localhost:8000/health

# List containers (replace with your actual API_SECRET)
curl -H "X-Api-Key: change-this-to-a-strong-random-secret" http://localhost:8000/containers

# Chat with the LLM
curl -X POST http://localhost:8000/chat \
  -H "X-Api-Key: change-this-to-a-strong-random-secret" \
  -H "Content-Type: application/json" \
  -d '{"message": "What is the best way to debug a crashing container?"}'

# Analyze logs of a container
curl -H "X-Api-Key: change-this-to-a-strong-random-secret" \
  http://localhost:8000/containers/dockermind-master/logs/analyze

# Auto-heal a container
curl -X POST http://localhost:8000/heal \
  -H "X-Api-Key: change-this-to-a-strong-random-secret" \
  -H "Content-Type: application/json" \
  -d '{"container_name": "dockermind-master"}'

# List registered slaves
curl -H "X-Api-Key: change-this-to-a-strong-random-secret" http://localhost:8000/slaves
```

## Adding a slave on a REMOTE server

On the remote server:

```bash
# 1. Copy slave binary and certs
scp -r dockermind/slave/          user@remote-server:~/dockermind-slave/
scp -r dockermind/master/certs/   user@remote-server:~/dockermind-slave/certs/

# 2. On the remote server, run the slave
cd ~/dockermind-slave
docker build -f Dockerfile.slave -t dockermind-slave .
docker run -d \
  --name dockermind-slave \
  --restart unless-stopped \
  -v /var/run/docker.sock:/var/run/docker.sock:ro \
  -v $(pwd)/certs:/app/certs:ro \
  -p 8080:8080 \
  -e SLAVE_ID=slave-server2 \
  -e MASTER_URL=https://YOUR_MASTER_IP:8000 \
  -e CA_CERT=/app/certs/ca.crt \
  -e SLAVE_CERT=/app/certs/slave.crt \
  -e SLAVE_KEY=/app/certs/slave.key \
  dockermind-slave
```

## API reference

| Method | Endpoint                              | Description                         |
|--------|---------------------------------------|-------------------------------------|
| GET    | /health                               | Health + LLM + slave count          |
| POST   | /chat                                 | Ask the LLM anything                |
| GET    | /containers                           | List containers on master host      |
| GET    | /containers/{name}/logs               | Fetch last N log lines              |
| GET    | /containers/{name}/logs/analyze       | LLM log analysis                    |
| POST   | /containers/{name}/restart            | Restart container                   |
| POST   | /containers/{name}/start              | Start container                     |
| POST   | /containers/{name}/stop               | Stop container                      |
| POST   | /containers/exec                      | Exec command in container           |
| POST   | /heal                                 | Fetch logs → LLM → auto-heal        |
| GET    | /slaves                               | List all slave nodes                |
| POST   | /slaves/register                      | Register a slave (called by slave)  |
| POST   | /slaves/heartbeat                     | Slave heartbeat (called by slave)   |
| WS     | /ws                                   | WebSocket live event feed           |

## Project structure

```
dockermind/
├── master/
│   ├── main.py              FastAPI app — all routes + WebSocket hub
│   ├── config.py            All env vars in one place
│   ├── llm_client.py        Ollama REST wrapper + log analysis
│   ├── docker_ops.py        Docker SDK operations
│   ├── slave_registry.py    In-memory slave registry + heartbeat
│   ├── requirements.txt
│   ├── Dockerfile.master
│   └── certs/               mTLS certs (generated by gen_certs.sh)
├── slave/
│   ├── main.go              Entrypoint, config, registration, heartbeat
│   ├── docker_watcher.go    Container monitoring + log forwarding
│   ├── executor.go          HTTP server + Docker command execution
│   ├── go.mod
│   └── Dockerfile.slave
├── scripts/
│   └── gen_certs.sh         One-time mTLS cert generator
├── docker-compose.yml
├── .env.example
└── README.md
```
